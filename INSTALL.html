Neural Brain MCP Server

Dein Obsidian Vault als semantisches Arbeitsgedaechtnis fuer Claude. 6 MCP Tools, FAISS Vektorsuche, SQLite + FTS5, Live-Sync per Watchdog.

Obsidian Vault (.md files) | v Scanner ──parse──> Embedder ──vectors──> FAISS Index | | v v SQLite + FTS5 <────── queries ────── MCP Server (stdio) | | v v Watchdog (live sync) Claude Code / Desktop

3 Brain konfigurieren

Die Config liegt unter ~/.neural-brain/config.json. Erstelle sie oder passe an:

{
    "vault_path": "C:\\Users\\DEIN_USER\\pfad\\zum\\Obsidian Vault",
    "auto_index": true,
    "index_on_startup": true,
    "model_name": "paraphrase-multilingual-MiniLM-L12-v2",
    "folder_to_region": {
        "02 Projekte": 0,
        "05 Referenzen": 2,
        "01 Lucas": 3,
        "04 Sessions": 3,
        "03 Agenten": 6,
        "00 Index": 8
    }
}
Wichtig: vault_path muss auf den Root-Ordner deines Obsidian Vaults zeigen. Alternativ per Environment Variable: BRAIN_VAULT_PATH=...

4 Vault vorab indexieren (optional)

Der erste Start laedt das Embedding-Modell (~90MB) und indexiert alle Notes. Das kann 1-2 Minuten dauern. Du kannst den Index auch vorher bauen:

# Normaler Index-Aufbau (nur neue/geaenderte Notes)
python -m brain_mcp index

# Mit explizitem Vault-Pfad
python -m brain_mcp index --vault "C:\pfad\zum\vault"

# Kompletter Neuaufbau (alle Notes re-embedden)
python -m brain_mcp index --force

5 MCP Server in Claude registrieren

Option A: Claude Code (CLI)

Bearbeite ~/.claude/.mcp.json:

{
  "mcpServers": {
    "neural-brain": {
      "command": "python",
      "args": ["-m", "brain_mcp", "serve"],
      "env": {
        "BRAIN_VAULT_PATH": "C:\\Users\\DEIN_USER\\pfad\\zum\\vault"
      }
    }
  }
}

Option B: Claude Desktop App

Bearbeite %APPDATA%\Claude\claude_desktop_config.json (Windows) oder ~/Library/Application Support/Claude/claude_desktop_config.json (Mac):

{
  "mcpServers": {
    "neural-brain": {
      "command": "python",
      "args": ["-m", "brain_mcp", "serve"],
      "env": {
        "BRAIN_VAULT_PATH": "C:\\Users\\DEIN_USER\\pfad\\zum\\vault"
      }
    }
  }
}
Tipp: Claude Code und Claude Desktop lesen verschiedene Config-Dateien. Trage den Server in beide ein, wenn du ihn ueberall nutzen willst.

# Claude Code neu starten - der MCP wird automatisch geladen

Erster Start: Dauert 30-90 Sekunden weil das Embedding-Modell geladen und der Vault indexiert wird. Danach startet der Server in unter 5 Sekunden.

7 Die 6 MCP Tools

brain_retrieve

Semantische Suche ueber alle Notes. Findet per Bedeutung, nicht nur Keywords.

query region limit threshold

brain_context

Kontextrelevante Notes fuer aktuelle Arbeit. Kombiniert Dateinaehe + Semantik.

file_paths task_description depth

brain_store

Note erstellen oder updaten im Vault. Wird sofort indexiert.

title content region tags

brain_related

Verwandte Notes finden per Semantik + Backlinks.

title path limit

brain_recent

Kuerzlich geaenderte Notes. Activity Feed fuer den Vault.

days region limit

brain_regions

Hirnregionen auflisten, beschreiben oder anpassen.

action region description
